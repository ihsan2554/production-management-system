# Contributing

This project is a learning / case-study project (Praktek Lapang, Universitas Pakuan) and is a fork of [mrezadit's Production Management System](https://github.com/mrezadit), built on [CodeIgniter 3](https://codeigniter.com).

Suggestions and bug reports are welcome.

## How to contribute

1. Fork this repository
2. Create a branch for your change (`git checkout -b fix/short-description`)
3. Commit your changes with a clear message
4. Push the branch and open a Pull Request

## Guidelines

- One change per Pull Request
- Test the affected flow (Admin and Leader) before submitting
- For bugs, include the steps to reproduce and the page / URL involved
- Do not commit real credentials; the demo accounts in `READMEEE!!!.txt` are for local use only
